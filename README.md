# Yaswanth Manoj — Portfolio
React + Vite + Tailwind CSS v3 + Framer Motion + Lucide.

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # outputs dist/

Contact details live in `src/data/site.js`; projects, status and links in `src/data/projects.js`.
Deploy: push to GitHub, import the repo in Vercel (Framework: Vite, build `npm run build`, output `dist`).
